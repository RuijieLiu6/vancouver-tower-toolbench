# Vancouver Tower Toolbench

Small tools for designing a high-rise in Vancouver, by Ruijie Liu and Sinnie Choi (ARCH 540, UBC SALA, fall 2026, studio instructor Xun Liu).

Live site: https://ruijieliu6.github.io/vancouver-tower-toolbench/

The site has four tabs: About us, How it works, Try the tools, Give feedback. It is one static page (`index.html`) with its images and diagrams; nothing to build or install.
